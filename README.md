# The Antique Recipe Archive

A free, static website prototype. Open index.html through a web server because the site fetches recipes.json.

## Hosting

Cloudflare Pages: connect this GitHub repository, select the main branch, use no framework preset and no build command, and set the output directory to / (repository root). Deploy.

## Content

Add entries to recipes.json to expand the collection. Seven initial records are examples, not seven authenticated full transcriptions. Original sources must be checked before claiming verification; modern adaptations must be tested and clearly distinguished. This prototype is not a production SEO or advertising implementation.
